# Harvest Scope Network Monitor Probe

NEM・Symbolの公開ノードを検査し、結果を[Harvest Scope Network Monitor](https://monitor-api.7338.work/)へ送る、任意参加のProbeです。

参加・一時停止・撤退は自由です。稼働保証、障害対応、ログ提出、撤退の事前連絡は求めません。VPS代や通信料は参加者の負担となります。

現在の試験配布版は **`0.1.1-test.20261105.1`**（Probeの実行時版は`0.1.1`、プロトコルはv2）です。NIS1の補助APIが失敗しても、取得済みの対象ノードの高さを保持する修正を含みます。[配布情報](releases/0.1.1-test.20261105.1/release.json)と[更新・切戻し手順](releases/0.1.1-test.20261105.1/README.md)を公開しています。

## 参加するには

現在の配布対象は、Linux・amd64（x86_64）の試験版です。Docker Composeで動かします。受信用ポートの開放、ウォレット、秘密鍵、既存ノードのデータは不要です。arm64の実機受け入れ確認は済んでいません。

[参加者向け手順](docs/participant.md)に沿って配布情報の署名・有効期限を確認し、検証したイメージを取得して起動してください。公開GHCRイメージの取得に、GitHubアカウントやログインは不要です。更新は手動で行います。

初回は`trial`（試験参加）で登録されます。通常の稼働実績を確認して`active`（通常参加）へ自動承認する仕組みを用意していますが、現在の試験運用では自動承認を保留しています。`trial`のままでも、繰り返し登録する必要はありません。

`contributor`は`active`の参加者のうち、希望者がProbe IDを運営へ提出し、確認を受けて付く役割です。通常参加とは別で、希望しなくても参加できます。

## 初期設定の上限

| 項目 | 設定 |
| --- | --- |
| CPU | 0.2コア |
| メモリ | 448MiB |
| 同時検査 | 4件 |
| 要求速度 | 毎秒3件、burst 4 |
| 通信予算 | 20GiB/日 |
| 未送信結果の保存枠 | 100MiB |

通信予算は上限であり、毎日その量を使う指定ではありません。資源や通信の上限は参加者が下げられます。設定や停止・撤退の操作は[参加者向け手順](docs/participant.md)を参照してください。

不具合や手順の質問は[GitHub Issues](https://github.com/tikpok/harvest-scope-probe/issues)へお寄せください。鍵や認証情報は投稿しないでください。
